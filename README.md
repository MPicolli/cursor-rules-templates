# Cursor Rules Templates

Coleção de regras (`.mdc`) para otimizar o fluxo de trabalho com o Cursor AI, automatizando a criação de contexto e aprimorando respostas de código.

## 📁 Estrutura do Repositório

```text
cursor-rules-templates/
├── .cursor/
│   └── rules/
│       ├── cursor-rules.mdc
│       └── self-improvement.mdc
└── README.md
```

## 📄 Arquivos Inclusos

- `.cursor/rules/cursor-rules.mdc`: Diretrizes para a IA gerar novas regras automaticamente conforme o projeto evolui.
- `.cursor/rules/self-improvement.mdc`: Instruções para refinamento contínuo de respostas e padrões de desenvolvimento.

## 🚀 Como Usar

Basta copiar a pasta `.cursor` para a raiz do seu projeto de destino:

```bash
cp -r .cursor/ /caminho/do/seu-projeto/
```

Alternativamente, crie manualmente a pasta `.cursor/rules/` no seu projeto e copie os arquivos `.mdc` para dentro dela.
